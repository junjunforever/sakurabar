CLOUDFLARE PAGES — FASTEST DEPLOYMENT
1. Log in to Cloudflare.
2. Go to Workers & Pages.
3. Create application > Pages > Upload assets / Direct Upload.
4. Upload the CONTENTS of this folder (or upload the ZIP if Cloudflare accepts it in your current UI).
5. After deployment, open the Pages project > Custom domains.
6. Add: sakurasaketokyo.com
7. Since the domain is already on Cloudflare, DNS/SSL should be configured automatically.
